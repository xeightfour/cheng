# Project Cheng

Cheng is a graphics project using GLFW and GLEW.

## Dependencies

- [GLFW](https://www.glfw.org/)
- [GLEW](https://glew.sourceforge.net/)
- libjpeg

## Setup

1. Clone the repository
   ```sh
   git clone https://github.com/xeightfour/cheng.git
   cd cheng
   ```
2. Build the project
   ```sh
   make
   ```
